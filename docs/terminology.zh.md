# Eyot 术语（中文）

给人读的版本。代码、数据库、API 继续用英文标识符；Portal 界面用这里的中文。产品为什么这样切，见 [`design.zh.md`](design.zh.md)。英中一览见 [`metaphor-name-table.md`](metaphor-name-table.md)，英文释义见 [`terminology.md`](terminology.md)。

读完下面两棵树，后面的词都能对上号。

---

## 两棵树

### 地方：大陆 → 区域 → 生境

```
平台（System，逻辑控制面，不是一张业务表）
 └── 大陆 Organization          租户边界
       └── 区域 Namespace       场景分区（不是 dev/staging/prod）
             └── 生境 Workspace 这个场景里的一条具体工作流
```

例子：大陆里可以有区域 `coding` 和 `social-media`。`social-media` 里再开生境「公众号」和「小红书」。**血脉绑在区域上**，所以同一套身份和记忆可以在该场景的多个生境里复用；真正跑起来的后裔才落在某一个生境里。

单租户默认也成立：`1 大陆 → 1 区域 → 1 生境`，从空画布开始。

### 生命：始祖 → 血脉 → 后裔

从大到小：

| 层 | 英文 | 中文 | 住在哪 | 是什么 |
|---|---|---|---|---|
| L1 | BaseClass | **始祖** | 平台 / 大陆（也可到区域） | 角色原型：狐狸、海狸……业务无关 |
| L2 | Entity | **血脉** | **区域** | 这个场景里的具体身份 + 记忆 |
| L3 | Instance | **后裔** | **生境** | 正在跑的那一个（一个 pod） |

始祖回答「这是什么角色、这份活最适合怎样的 harness」。血脉回答「它在这个场景里是谁、记得什么、带哪些基因」。后裔回答「此刻在哪条工作流里，作为这个角色的 harness 入口在跑」。

约束：同一个生境里，同一条血脉最多一个活跃后裔——因为对话里的 `@slug` 指的是血脉，不能歧义。后裔身上的能力 / 基因应当够这份角色把一串任务做完。

没有职级。不存在浅识者 / 深潜者 / 觉醒者这套轴。

## 地方怎么切

**大陆（Organization）**  
隔离顶层。里面有自己的区域、自建始祖、基因、智能（LLM 供应）、成员授权。登录后先选大陆；你没有加入的大陆看不见。

**区域（Namespace）**  
按**业务场景**切，不是按环境切。血脉、该场景的小脑、区域内的生境，都挂在这里。

**生境（Workspace）**  
场景里的一条工作流。画布、兽道、信号塔、标本、正在跑的后裔，都在这里。表名就是 `workspaces`。

**迁徙路线**  
领地地图的背景意象，不是一张表。

---

## 谁在场

**智人**  
真人在生境画布上的节点（Membership 的 user 行）。

**生物**  
后裔在画布上的节点（Membership 的 instance 行）。狐狸、海狸这些动物名是始祖的显示名；落到画布上，AI 成员统称生物。

**成员**  
用户加入某个区域。不再单独造一个神秘名词。大陆侧的授权关系是 OrganizationContract：没有这一行，这座大陆对你不存在。

鉴权认的是 **智人基因** 原子（`can_*`），写在大陆成员关系（OrganizationContract）上，区域成员可以再收窄或补授权。界面上的「管理员」是算出来的，不是一张静态 role 列。

## 五个始祖

常驻、有长久记忆、可以占领地地图的，只有这五个。显示名是动物，slug 是英文。

| slug | 显示 | 干什么 |
|---|---|---|
| `fox` | 狐狸 | 谋划、计划模式、写计划 |
| `beaver` | 海狸 | 一个人把活做完的全栈 |
| `sparrow` | 麻雀 | 快、吞吐高（不要写成「廉价」） |
| `coyote` | 郊狼 | 自己跑很深的长任务 |
| `lion` | 狮子 | 委派、盯进度、把关 |

另外六种「只干一趟就结束」的能力（意图分析、读架构、质检、探索、外搜、看图）**不是始祖**。它们没有动物名、不占地图、没有血脉卡片，只作为后裔 pod 内部的 **subagent 能力**，由始祖声明自己会不会用。

## 协作与空间

**领地地图（Topology）**  
生境的旗舰面：节点、发光（跟着后裔心智状态）、点选 / 连线 / 移动、消息在兽道上流动。

**兽道（Passage）**  
两个在场节点之间的邻接边。消息只走邻居，没有全场广播。

**信号塔（CentralHub）**  
每个生境一座协作中枢，四块：

1. **粮仓（Fornix）** — 正在用的共享文件。pod 上是 `shared/`；`work/` 是私有临时区，做完要迁进共享。
2. **额叶** — 看板。
3. **脑干** — 调度 / 定时。
4. **小脑** — 系统智能体。每个**区域**一条小脑血脉（`is_cerebellum`，不出现在普通血脉列表）；第一个生境创生血脉 + 后裔，之后的生境只给同一条血脉再开后裔。远期工单里，需求交给**这片生境的小脑后裔**，由它回结论。

**标本（Vault）**  
冷归档。现在是数据库键值，对象存储以后再说。

**星球中枢（SystemHub）**  
大陆级入口。现在：短会话（写描述、给默认模型）。远期：可按工单生成并部署一套生境网络。不是生境里的小脑。

**工单（远期）**  
提单人提交的一份需求。不是现在的表。产品意图见 [`design.zh.md`](design.zh.md) §10.3。

**智能（OrganizationProvider）**  
这座大陆用哪家模型。

## 能力、基因、知识

真人侧和 AI 侧不是一张表。

| | 真人 | AI |
|---|---|---|
| 基因 | **智人基因**：权限原子 `can_*` | **生物基因**：技能 / 工具 / 命令打成一包（写在 manifest 里） |
| 能力目录 | — | **能力市场**：可增删改的能力条目 |

**知识**是独立的表，按范围分层：平台 → 大陆 → 区域 → 生境。两套维度分开管：

- **require**：基因 / 能力声明「发挥它需要哪些知识」
- **has**：始祖 / 血脉 / 后裔实际拥有的知识，向下继承；创生后裔时注入运行配置

同名覆盖：生境 > 区域 > 大陆 > 平台。创生时若 has 盖不住 require，只提示缺什么，不阻断。

## 记忆怎么长回去

**记忆（Memory）** 挂在血脉上，只追加、不改写。后裔跑出来的经验先写进这条血脉，而不是写进某一个 pod 然后跟它一起死。

三条动作，两条链，不要揉成「四级跳」：

| 动作 | 中文 | 从哪到哪 |
|---|---|---|
| distill | **领悟** | 记忆 → 能力 |
| promote | **蜕变** | 后裔 → 血脉（运行里长出来的东西写回去） |
| transmute | **演化** | 血脉 → 新的始祖 |

```
内容链：  记忆 ──领悟──▶ 能力 ──打包──▶ 生物基因
身份链：  后裔 ──蜕变──▶ 血脉 ──演化──▶ 始祖
```

创生后裔或血脉的动词是 **创生**。

## 运行时（两层，不要混）

**外层：Eyot（harness for harness）**  
Portal、组网、兽道投递、信号塔、部署、可观测。调度的是一只只角色 harness。

**内层：后裔（角色 harness）**  
每个后裔是一个 harness agent 入口，循环工程装在 pod 里并按始祖特化。驱动循环的 runtime 首选 **pi**（React runtime 可选项）。不是 Senpi CLI。Senpi / oh-my-openagent 是「单只 harness」那一层的同类，不是 Eyot 外层。

当前线上是 **托管运行时**：Eyot 创生并管这个 runtime。远期可以 **外接** 已经在本机或远程跑着的 runtime，绑到既有后裔上。无论哪种，同一个后裔生命周期内不热切换；外接也不会自动给你本机目录，目录要单独授权、挂载或走文件桥。

投递给正在跑的后裔有三态：**notify**（只留线索）、**soft_inject**（安全点插入）、**wake**（空闲则开一轮）。没有兽道时，人类 `@` 不会偷偷打到对方 Host。

**心智状态（LoopState）** 是控制面看到的循环状态（跑着 / 空闲 / 暂停 / 打断 / 完成 / 失败），决定节点怎么发光。

## 几个容易混的

- **区域 ≠ 环境。** 它是场景，不是部署阶段。
- **血脉 ≠ 后裔。** 血脉是身份和记忆；后裔是这一次跑起来的身体。
- **小脑 ≠ 星球中枢。** 小脑是区域内的系统血脉，在每片生境有一只后裔，负责这片生境的收口；星球中枢是大陆级入口（现在是短会话，远期可按工单搭网）。
- **后裔 ≠ 通用聊天。** 后裔是按角色装好的 harness 入口，不是任意 prompt 的会话窗。
- **智人基因 ≠ 生物基因。** 一个是人的权限原子，一个是 AI 的能力包。
- **粮仓 ≠ 标本。** 粮仓是正在用的共享目录；标本是冷归档。
- **pi ≠ Senpi。** pi 驱动后裔循环；Senpi 那一族是「单只 harness」的产品面，不是 Eyot 外层。
- **工单入口 ≠ 会话引擎 v2。** 工单是分权搭网收口的远期主入口；会话引擎是传输和多模态协议重建。
